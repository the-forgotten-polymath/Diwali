✨ NPM: diwali-animations

Happy Diwali 🪔

Automatic Rocket Fireworks • 60 FPS • Click screen to launch extra
NPM Usage 
// Install: npm install diwali-animations
import { startRocketShow, hangingLanterns, diyas, labrador, lanterns } from 'diwali-animations';

// 🚀 Continuous rockets from bottom:
startRocketShow(850);

// 🏮 Hanging lanterns with mouse proximity transparency:
hangingLanterns(10);

// 🪔 Docked diyas (corners cleared):
diyas({ count: 9, clearCorners: true });

// 🐕 Labrador eating treats in bottom-left:
labrador();

// 🏮 Sky floaters ascending bottom to top:
lanterns({ continuous: true, position: 'full' });
